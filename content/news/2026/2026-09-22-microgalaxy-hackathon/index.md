Now that our [microGalaxy community](https://galaxyproject.org/community/sig/microgalaxy/) paper is accepted, we can focus more on tool maintenance! As discussed in our last meeting, many — also highly used — microGalaxy tools are outdated, as tracked in this [IUC issue](https://github.com/galaxyproject/tools-iuc/issues/8301).

We therefore plan a **hackathon for tool development** to update those tools:

| | |
|---|---|
| **Date** | October 14th, 2026 (one day) |
| **Location** | Online |
| **Time** | all day, 10 am CEST to open end |
| **Cost** | Free |

The main idea is to block some time for everyone that allows this work and also coordinate a bit on who does what. It's perfectly fine if there is only a short US/AU/EU overlap — the day can still serve as a dedicated block of time that you can use for tool maintenance.

The list of tools needing updates (sorted by usage on usegalaxy.eu), including existing pull requests and status, is available in the [IUC issue #8301](https://github.com/galaxyproject/tools-iuc/issues/8301). Please comment on the issue to indicate which tool(s) you intend to work on and to avoid duplication of effort.

We will coordinate on the microGalaxy Matrix channel: [https://matrix.to/#/#galaxyproject_microGalaxy:gitter.im](https://matrix.to/#/#galaxyproject_microGalaxy:gitter.im)
