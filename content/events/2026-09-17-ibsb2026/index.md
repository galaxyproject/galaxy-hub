Join [Diana Chiang Jurado](https://github.com/dianichj) from the [University of Freiburg](https://uni-freiburg.de/en/) at [IBSB 2026](https://asb-conference.hki-jena.de/ibsb2026), where she will give a talk at the symposium and serve as trainer for the Galaxy session of the [workshop](https://asb-conference.hki-jena.de/workshops) "Image analysis with BAND, Nextflow and Galaxy".

The talk will introduce Galaxy for FAIR bioimage analysis, covering the platform itself, its interface, available tools, and the tutorials and training materials now available for image analysis.

**Symposium dates**: September 17–18, 2026

**Workshop dates**: September 16–17, 2026 (Diana's session: Thursday, 08:30–11:30)

**Location**: Leibniz-HKI, Jena, Germany

## Workshop session: Bioimage analysis with Galaxy

**Instructor**: Dr. [Diana Chiang Jurado](https://galaxyproject.org/hall-of-fame/dianichj/)

On Thursday, this session introduces FAIR bioimage analysis using Galaxy, a free and open-source web platform accessible to any researcher, with tools and workflows that can be used without programming experience. Through a hands-on tutorial based on a specific use case, participants will explore the tools and workflows Galaxy offers for bioimage analysis, and learn how to use this resource to build and adapt their own workflows for image analysis tasks.

Before attending, participants should create a free account at [usegalaxy.eu](https://usegalaxy.eu/). No software installation is required as all analysis runs in the browser.

Diana Chiang Jurado is a member of the Galaxy [Image Analysis Community](https://galaxyproject.org/community/sig/image-analysis/) (SIG), which supports researchers using Galaxy for bioimage analysis. This community welcomes anyone working with image analysis, whether to contribute tools and expertise, share use cases and needs, or help shape the resources available for the image analysis community going forward!
