# GCC2027 CollaborationFest (CoFest!)

CoFest is a community gathering by those interested in contributing to Galaxy's
tool set, documentation, training materials, code base, and anywhere else that
expands the Galaxy ecosystem.

CoFest will be held immediately following the main GCC2027 conference. Exact
dates are to be announced.
