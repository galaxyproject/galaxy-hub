_Make your command-line tool usable by thousands of researchers - without them ever touching a terminal._

Wrapping a tool for Galaxy makes it findable, reproducible and usable in workflows on public Galaxy servers. In this one-day hackathon you bring your own command-line tool, learn how a Galaxy tool wrapper works, test it with Planemo, and open a pull request to the [Intergalactic Utilities Commission (IUC)](https://github.com/galaxyproject/tools-iuc) repository - the route to the Galaxy Tool Shed.

The hackathon is organised by SURF within the NWO TDCC-LSH project "FAIR tool framework". All work happens on [SURF Research Cloud](https://www.surf.nl/en/services/surf-research-cloud), in a workspace with Planemo and conda pre-installed.

# 🧰 Requirements for the tool

- It runs non-interactively from the command line: one command, no prompts and no GUI.
- Its inputs and outputs use file formats Galaxy already supports
- It has an open-source license that allows redistribution.
- It has not already been wrapped for Galaxy - check the [Galaxy Tool Shed](https://toolshed.g2.bx.psu.edu) and [tools-iuc](https://github.com/galaxyproject/tools-iuc). Updating an outdated existing wrapper is also a welcome project.

# 💻 Prerequisites

- Comfortable working in a Linux terminal: editing files, running commands, reading error messages
- Basic Git: clone, commit, push
- Familiar with the tool's command-line options and typical use, as its developer or as an experienced user
- Your own laptop with a web browser and an SSH client
- A GitHub account with an SSH key or personal access token set up
- Access to SURF Research Cloud - a setup guide is sent to registered participants
- A small test input (< 1 MB) for your tool and the output it should produce
- New to Galaxy? Follow the [Galaxy Training Network introduction](https://training.galaxyproject.org) beforehand
