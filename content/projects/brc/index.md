## Analytics for pathogen, host, and vector data

BRC Analytics lets you analyze your own data in the genomic context of pathogen,
host, and vector organisms. It brings together reference genomes from NCBI
Datasets, assembly views in the UCSC Genome Browser, curated Galaxy workflows,
and free compute at TACC, so an analysis can be set up and run without leaving
the browser: pick an organism, pick an assembly, pick a workflow, run it in
Galaxy.

BRC Analytics is part of the Bioinformatics Resource Centers for Infectious
Diseases program developed and funded by NIAID, and is built by the Galaxy, UCSC
Genome Browser, HyPhy, and TACC teams.
