# ESG4Stars News

This page lists news posts about the ESG4Stars project.

## Contribute

To add a news item, create a new folder within the news folder using the year bucket layout, for example `content/news/2026/my-news-item/index.md`. Add `esg4stars` to its tags, or the news item won't show up here.
