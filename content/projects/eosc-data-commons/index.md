## Data discovery, access and analysis across EOSC

EOSC Data Commons builds services for inter- and cross-disciplinary data
discovery, access, sharing and reuse within the
[EOSC](https://digital-strategy.ec.europa.eu/en/policies/open-science-cloud)
Federation. Its goals include an analytics-oriented metadata warehouse and
discovery service, a federation of data repositories enhanced with scientific
applications, a catalogue of data analytics tools, an execution service for
running them, and tooling for FAIRness assessment and reproducibility.

The project is funded by the European Union under
[grant agreement 101188179](https://cordis.europa.eu/project/id/101188179), and
[kicked off in April 2025](/news/2025-04-07-data-commons/).

- Project website: [eosc-data-commons.eu](https://www.eosc-data-commons.eu/)

## Galaxy's part in it

The European Galaxy team contributes the analysis half of the problem — what
happens once a researcher has found the data. Galaxy works in two work packages:

**WP5, Data Commons Preparation** (led by [SWITCH](https://www.switch.ch/en)):
harmonised APIs for tool and data registries, a federated catalogue of tools,
specifications for processing requests, and applications that match datasets to
the tools that can analyse them.

**WP6, Data Analysis Orchestration and Deployment** (led by
[CESNET](https://www.cesnet.cz/en)): deploying analysis packages across compute
infrastructures, integrating established deployment mechanisms, and abstraction
layers for data access.
